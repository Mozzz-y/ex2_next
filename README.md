# Profile Next Project

Простой проект страницы профиля на Next.js, TypeScript, Tailwind CSS и Lucide React.

## Запуск

1. Установите Node.js 18.17+.
2. Откройте папку проекта в терминале.
3. Выполните:

```bash
npm install
npm run dev
```

4. Откройте http://localhost:3000

## Структура

- `app/page.tsx` — основная страница профиля.
- `app/globals.css` — базовые стили.
- `app/layout.tsx` — настройки страницы.
- `tailwind.config.ts` — настройки Tailwind.
- `package.json` — зависимости проекта.

## Что работает

- Профиль пользователя.
- Статистика.
- Навыки и контактная информация.
- Переключение табов.
- Адаптивная верстка.
- Иконки Lucide.
- Кнопки и ссылки имеют базовые состояния hover.
